# Fotos de productos Vonixx

Estas fotos se subieron para crear los productos directamente desde el panel:

| Archivo | Producto |
|---|---|
| `alumax.jpg` | Vonixx Alumax (ej: 500 ml y 1,5 L como 2 tamaños en 1 producto) |
| `Darker.jpg` | Vonixx Darker |
| `Hybrid-wax.jpg` | Vonixx Hybrid Wax |
| `Removex.jpg` | Vonixx Removex |
| `V-FLOC.jpg` | Vonixx V-FLOC |

Ojo: el nombre de archivo es case-sensitive (`Darker.jpg` con mayúscula).
Al crear el producto en `/admin/productos` poner como imagen `/productos/alumax.jpg`
y cargar cada tamaño como una tamaño (no como productos separados).
